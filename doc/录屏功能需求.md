# 录屏功能需求（Feature Spec）

> 状态：**主体已实现**（2026-11-05 回填）。录屏主链路（热键/托盘/HUD、显示器·区域·窗口·虚拟屏、H.264 MP4、系统声+麦克风混音、暂停/恢复、崩溃恢复）已可用并有 E2E 回归；剩余缺口见第 3 节「现状」列与第 7 节勾选框。
> 平台：Windows 10 1903+ / Windows 11
> 技术底座：WGC 抓屏 + Media Foundation 编码 + WASAPI 音频，H.264 / MP4，零新增第三方依赖
> 关联文档：[录屏方案.md](录屏方案.md)（可行性、MF 踩坑）、[实现契约.md](实现契约.md)（分层约束）、[README.md](../README.md)（运行手册与已知限制）
> 回归网：[scripts/e2e_record.ps1](../scripts/e2e_record.ps1)（已接入 `scripts/verify_all.ps1`）、[scripts/e2e_encoder_host.ps1](../scripts/e2e_encoder_host.ps1)（编码子进程隔离 / 卡死恢复）

---

## 0. 一句话目标

把「`--record N` 能录单显示器」补成用户日常可用的录屏功能：
**热键/托盘一键开始停止、HUD 可控、可选显示器/区域/窗口、可录系统声和麦克风、可暂停、可靠收尾、配置可保存。**

---

## 1. 目标与非目标

### 1.1 必须达到

| 维度 | 目标 |
|---|---|
| 入口 | 全局热键、托盘菜单、HUD 按钮、命令行四种方式都能开始/停止 |
| 目标 | 主显示器、指定显示器、屏幕区域、单个窗口；后续支持整块虚拟屏 |
| 声音 | 系统声音（WASAPI loopback）与麦克风，可单独开关、可混音 |
| 控制 | 倒计时、暂停/继续、放弃、实时计时、静音 |
| 可靠性 | 任何停止路径都能写出可播放 MP4；磁盘不足、显示器变化、窗口关闭都不能留下坏文件 |
| 性能 | 1080p30 硬件编码路径下丢帧 < 1%，不拖慢截图/UI 线程 |
| 可配置 | 帧率、码率、目录、目标、音频、光标、倒计时等可保存并在设置窗口修改 |

### 1.2 明确不做

- 直播推流、云录制、会议共享
- 视频剪辑、字幕、转码、滤镜
- 摄像头画中画、多轨音频编辑
- 上传/分享到微信或第三方服务
- macOS / Linux

## 2. 用户故事

| ID | 场景 |
|---|---|
| US-1 | 按 `Alt+R` 立刻录主屏，右下角出现 HUD，再按一次停止，文件自动出现在 `Videos\Screenloom` |
| US-2 | 只录某个窗口，窗口被其它窗口挡住也能录到；窗口关闭时自动停止并保留已录内容 |
| US-3 | 框选屏幕上一块区域录制动图/演示，区域位置固定 |
| US-4 | 录一段带讲解的演示：系统声 + 麦克风都进视频，能随时静音麦克风 |
| US-5 | 录到一半接电话，点暂停，回来后继续；成片里不包含暂停的那段时间 |
| US-6 | 录 1 小时课程，中途磁盘快满时提前告警并安全收尾，文件可播放 |

| REC-100 | P0 | 线程模型 | 录制 worker 自己进 COM MTA；WGC/编码器对象在 worker 内创建和销毁；UI 线程只收状态 | ✅ worker 内 COM MTA；UI 线程只收 `WM_RECORDER_EVENT` |
| REC-101 | P0 | 单写线程 | 采集、转换、编码在同一 worker；队列只保留最新帧，积压丢旧 | ✅ |
| REC-102 | P1 | 编码器回退 | 硬件初始化/写入失败自动切软件；仍失败则收尾并保留可恢复文件 | ✅ 编码器改走**独立子进程**（`screenloom.exe --encoder-host`，同 exe 复用同一套 MF 代码）：MF 卡死可被 kill，已录分片**当场**重封装成可播 MP4（`[E2E]` B/E 用例）；子进程拉不起来自动回退进程内，录制仍成功（C 用例）。实测进程内路径 50 次采样卡死 3 次（≈6%），子进程路径不受影响 |
| REC-103 | P1 | 锁屏 / RDP | 锁屏、远程桌面断开时暂停或安全停止，恢复后不崩溃 | ⚠️ WGC 失败时降级 GDI；**不做暂停/安全停止** |
| REC-104 | P1 | 长时录制 | 连续 1 小时 1080p30 文件可播、时长误差 < 0.5 s、音画漂移 < 100 ms | ❌ 未验证 |
| REC-105 | P0 | 性能预算 | 1080p30 硬件路径 CPU ≤ 15%，软件路径 ≤ 35%；丢帧 < 1% | ❌ 未验证 |
| REC-106 | P1 | 资源泄漏 | 连续 50 次短录制，句柄/内存不持续增长 | ❌ 未验证 |
| REC-107 | P1 | 诊断日志 | `%TEMP%\screenloom_record.log` 记录目标、编码器、丢帧、错误、收尾结果 | ⚠️ 错误走 stderr；**无独立诊断日志文件** |
| REC-108 | P2 | GPU 零拷贝 | BGRA→NV12 走 GPU / DXGI Duplication；CPU 路径保留兜底 | ❌ |

## 5. 交互与状态机

```text
Idle
  │ 热键/托盘/HUD/CLI/倒计时结束
  ▼
Countdown ──取消──► Idle
  │
  ▼
Recording ◄──继续── Paused
  │  │                │
  │  └──暂停──────────┘
  │
  ├── 热键/托盘/HUD 停止
  ├── 达到时长/大小上限
  ├── 磁盘不足 / 编码停滞 / 目标消失 / 显示变化
  ▼
Stopping ──收尾成功──► Idle（保存正式文件）
         └─收尾失败──► Idle（保留 .partial + 报错）
```

**停止原因必须可区分**：用户停止、时长、大小、磁盘、目标关闭、显示变化、编码错误、应用退出。HUD/日志要显示原因，不能一律“录制失败”。

**暂停语义（建议）**：暂停时间从成片时间轴中剔除。例：录 5 s → 暂停 5 s → 再录 5 s，成片约 10 s，而不是 15 s 的黑帧/静止帧。

**倒计时语义**：倒计时期间不抓帧、不建编码器；取消后不产生文件。

## 8. 验收方案

### 8.1 单元测试

- 帧节奏：CFR 时间戳、卡顿不补写风暴、暂停偏移、尾帧补齐
- NV12：已知色块 → 期望 YUV；full range / BT.709
- 编码器：合成帧 → MP4 含 `ftyp`/`moov`/`mdat`；码率属性位置正确
- 配置：缺键默认、非法值校验、往返读写
- 状态机：非法转换被拒绝；停止原因正确
- 磁盘保护：阈值计算、剩余空间判断（可注入假值）
- 文件名：时间戳格式、冲突后缀、不覆盖

### 8.2 集成测试

| 用例 | 判据 |
|---|---|
| 10 秒主屏录制 | 文件存在；`ffprobe` 可读；`nb_read_frames ≈ duration × fps`（±2 帧） |
| 区域/窗口录制 | 尺寸等于目标；窗口被遮挡仍能录到内容；窗口关闭后文件可播 |
| 暂停/继续 | 5 s + 暂停 5 s + 5 s，成片 10 s ±0.3 s，无黑帧段 |
| 系统声 + 麦克风 | 存在 1 条 AAC 流；48 kHz / 立体声；音画偏差 ≤100 ms |
| 静音 | 对应时间段音频为静音，不是断流 |
| 显示器拔出/改分辨率 | 进程不崩；文件已 Finalize；提示原因 |
| 磁盘不足 | 提前告警；自动停止后文件可播 |
| 强杀进程 | 不产生“看似成功”的正式文件；`.partial` 可被检测 |
| 1 小时录制 | 文件可播；时长误差 <0.5 s；音画漂移 <100 ms |

### 8.3 E2E（PowerShell）

1. 启动 `screenloom.exe`，发送录屏热键；
2. 断言 HUD 窗口存在（`FindWindow`/`GetWindowRect`）；
3. 等待 10 秒，再发停止；
4. 断言 `Videos\Screenloom` 有新 `.mp4`；
5. `ffprobe` 校验 codec/分辨率/帧率/帧数/时长；
6. 清理测试文件。

### 8.4 手工矩阵

- 系统：Win10 1903、Win11
- 显卡：NVIDIA / Intel / AMD（至少两种）
- DPI：100% / 125% / 150% / 200%
- 显示器：单屏、双屏、三屏、混合 DPI、主副屏左右上下排列
- 目标：显示器 / 区域 / 窗口 / 虚拟屏
- 音频：无 / 仅系统 / 仅麦克风 / 两者
- 场景：静态桌面、视频播放、游戏全屏、锁屏、RDP、UAC 安全桌面
- 时长：10 秒、10 分钟、1 小时

## 9. 风险与待决策

### 9.1 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| WGC 窗口最小化/受保护内容 | 黑帧或冻结 | 明确提示；不承诺绕过 DRM |
| 多显示器逐帧合成 | CPU 高、接缝 | P2 再做；优先单显示器 |
| 窗口缩放导致帧池失效 | 录制中断 | P1 安全停止；P2 重建帧池/分段 |
| WASAPI 设备切换/独占 | 无声或崩溃 | 事件监听 + 静音兜底 + 明确提示 |
| fMP4/MF 崩溃恢复支持不明 | 强杀后文件坏 | 先做原型；不行就分段录制 |
| 设置窗口塞不下新字段 | 布局溢出 | P0 就加分页/滚动，不要事后补 |
| 热键被占用/全屏游戏 | 无法开始 | 注册失败提示；提供托盘入口 |
| HDR 屏 | 成片发灰 | P2 做 tone mapping 或录制前警告 |
| 4 GB 以上文件 | 播放器兼容性 | MP4 支持；验收覆盖 1 小时 |

### 9.2 待决策（建议值）

| 议题 | 选项 | 建议 |
|---|---|---|
| 暂停语义 | 剔除暂停时间 / 冻结画面 | **剔除**（成片更自然） |
| 系统声默认 | 开 / 关 | **开**（录屏最常见需求） |
| 麦克风默认 | 开 / 关 | **关**（避免隐私意外） |
| 鼠标指针默认 | 录 / 不录 | **录**（教学/演示需要） |
| 默认目标 | 主屏 / 上次 | **上次**，首次主屏 |
| 倒计时默认 | 0 / 3 / 5 秒 | **3 秒** |
| 窗口缩放 | 停止 / 重建继续 | P1 停止；P2 重建 |
| 设置窗口 | 加高 / 分页 / 滚动 | **分页 + 滚动** |
